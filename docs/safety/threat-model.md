## 1. 范围与方法

本清单描述单机 Windows 桌面应用在本项目威胁范围（in scope）内的威胁与滥用场景。威胁主体包括：

- 本机其他进程（探测、冒充或劫持本地 API）；
- 浏览器中的恶意页面（借用户会话发起跨站请求）；
- 恶意项目包作者（导入包中携带路径穿越、可执行载荷或资源炸弹）；
- 越权脚本（试图绕过能力与策略层的脚本配置）；
- 误用者（把工作台用于受保护在线游戏无人值守挂机）；
- 环境与系统本身（焦点、时钟、会话状态不确定）。

不在范围内（out of scope）：对用户设备的物理接触、操作系统级内核攻击、对目标程序服务端的网络攻击。

每条威胁包含：编号、场景描述、影响、缓解措施、缓解落点（模块/任务 ID）。安全用例编号（SAFE-*/SEC-*/AC-P0-*）引用任务文档 §9/§10，作为回归验证锚点。

## 2. 威胁清单

### TM-01 错误窗口输入

| 项 | 内容 |
|---|---|
| 场景描述 | 用户绑定目标 A 后，前台实际是窗口 B：可能是用户切走了窗口、出现同名窗口、目标重启后 HWND 被系统复用或 PID 已变化。输入若继续发出，将落入无关应用（如聊天窗口、终端）。 |
| 影响 | 在错误应用中执行按键/点击，可能发送消息、删除文件、执行命令；属最直接的用户伤害，是"错误条件下不会输入"的首要验收对象。 |
| 缓解措施 | 目标白名单（可执行文件、标题正则、窗口类、可选签名/哈希），模糊匹配不得自动放行；单会话目标锁绑定 PID/HWND/实例，目标重启或替换必须重新人工确认；每批动作执行前二次核验前台 HWND/PID/实例/会话/TTL；意图过期丢弃不补发。 |
| 缓解落点 | `services/input_broker`（INP-001、INP-005）、`packages/domain_model`/目标匹配（TGT-002、TGT-009）、前台监视（TGT-003）；用例 SAFE-001/002/003、AC-P0-01。 |

### TM-02 脚本越权（能力绕过）

| 项 | 内容 |
|---|---|
| 场景描述 | 脚本作者声明了超出实际需要的能力，或试图在 DSL/项目配置中引用未注册动作、未定义感知字段、未授权目标，甚至通过嵌入代码/系统调用绕过能力层直接操作系统。 |
| 影响 | 绕过 Policy Guard 与 Input Broker 的脚本可产生不受预算、目标白名单和模式约束的输入或系统操作；分享此类脚本即传播可执行代码（供应链风险）。 |
| 缓解措施 | 能力默认拒绝，脚本只能声明注册能力，不能绕过 Policy Guard（DOM-005）；DSL 静态分析检查不可达状态、无退出非终态、无限重试、未定义字段、缺失资产、越权动作及在线目标无人值守配置（DOM-007）；条件表达式只允许白名单运算和感知字段，禁止任意代码、反射和系统调用（FSM-001）；DSL、导入包和 UI 均无 exec/eval/shell 入口，插件默认关闭（SEC-001）；插件如引入必须独立进程、显式能力、可撤销、无管理员权限且无法直接访问 Input Broker（PLG-001/002，M4）。 |
| 缓解落点 | `packages/policy_engine`（DOM-005、POL-001）、`packages/domain_model`（DOM-007、SEC-001）、状态机编译器（FSM-001）；用例 FSM-007/008、SEC-004 用例（含可执行文件/脚本的项目包默认拒绝或隔离）、AC-P0-10。 |

### TM-03 恶意导入项目包（路径穿越 / Zip Slip / 可执行载荷）

| 项 | 内容 |
|---|---|
| 场景描述 | 导入的项目包内含 `../`、绝对路径、符号链接逃逸、设备路径条目（Zip Slip），或夹带 Python/PowerShell/批处理/DLL/快捷方式等可执行载荷，目标是逃出项目根目录写入文件或诱导执行代码。 |
| 影响 | 项目目录之外任意文件被覆盖或创建；可执行载荷若被运行等于任意代码执行，可进一步窃取数据或植入持久化。 |
| 缓解措施 | 安全解包与路径边界：拒绝绝对路径、`..`、符号链接逃逸、设备路径和超限解压（SEC-002）；文件存储限制路径、类型和大小，内容哈希去重，不可越出项目根目录（CTL-004）；导入/导出安全预检，展示能力、目标、文件和差异，拒绝恶意路径和超限包（VER-007）；资产来源、哈希和篡改检测（SEC-004）；签名校验，未知签名默认不启用真实输入（VER-006）；恶意与异常输入集纳入持续测试（TST-010）。 |
| 缓解落点 | `services/control_plane` 文件存储（CTL-004、SEC-002）、版本与发布（VER-006/007）、`packages/test_kit`（TST-010）；用例 SEC-003/004/005、AC-P0-11。 |

### TM-04 本地 API 劫持（无令牌 / 恶意 Origin）

| 项 | 内容 |
|---|---|
| 场景描述 | 本机其他进程扫描回环端口直接调用本地 API；或用户浏览器中的恶意页面在用户会话内向 `127.0.0.1` 的 API 发起跨站请求（无令牌、伪造 Origin/Host），试图注入意图、篡改项目或读取数据。 |
| 影响 | 未授权方可以读取项目与轨迹、启动/停止会话，最坏情况下注入输入意图（仍受 Input Broker 二次复核约束，但构成攻击链一环）；错误信息泄露细节有助于探测。 |
| 缓解措施 | 仅绑定 `127.0.0.1`；每次启动生成随机会话令牌，无令牌请求被拒绝（CTL-001）；拒绝未知 Origin、Host 和不兼容协议版本（CTL-002）；限权与攻击面检查覆盖端口绑定、CSRF/Origin、令牌、错误信息和速率限制（SEC-003）；契约测试固定消息样例与版本矩阵（TST-004）。 |
| 缓解落点 | `services/control_plane`（CTL-001/002、SEC-003）、IPC 决策（`docs/adr/ADR-0002-IPC与本地API.md`）；用例 SEC-001/002（无令牌 401 且不泄露敏感详情、恶意 Origin 请求被拒绝）。 |

### TM-05 按键卡死（崩溃 / 急停失效）

| 项 | 内容 |
|---|---|
| 场景描述 | 按键按下期间发生：运行时/控制面崩溃或被强杀；输入代理自身异常重启；UI 主线程卡死导致急停入口失效；Stop 被重复调用。任何一条路径若不释放按键，用户桌面上将留下"按住不放"的键。 |
| 影响 | 卡键持续触发目标应用（如长按移动、连续开火）；用户被迫手动干预，严重时造成输入失控；直接触碰一票否决项"急停或异常退出后存在未释放按键"。 |
| 缓解措施 | 按键状态账本与幂等释放：任何停止路径都能释放所有已按下键，重复释放无副作用（INP-004）；全局急停独立于 UI 线程，预览卡死仍能触发，首次触发立即停止输入、第二步再做清理，必须有不可取消的默认组合（INP-006）；父进程/代理看门狗：父进程退出、心跳中断或 Broker 异常后自动释放键并拒绝新意图（INP-007）；Broker 重启不重放旧队列，键状态进入安全复位（SAFE-011）。 |
| 缓解落点 | `services/input_broker`（INP-004/006/007）、桌面壳生命周期（UI-001）、崩溃恢复（CTL-009）；用例 SAFE-007 ~ 011/018、AC-P0-03/04/05。 |

### TM-06 日志与截图隐私泄露

| 项 | 内容 |
|---|---|
| 场景描述 | 运行截图与日志包含聊天内容、账号名、好友信息、系统通知、本机用户名与绝对路径；导出包、诊断包或缩略图绕过遮罩把敏感区域带出本机。 |
| 影响 | 用户隐私与凭据泄露；分享排障轨迹时把敏感画面/路径交给第三方；违反隐私保护要求（架构文档 §6.2 第 11 项）。 |
| 缓解措施 | 默认只保存 ROI 和触发异常前后的少量帧；提供固定遮罩区；日志自动脱敏窗口标题、路径和用户名；设置留存期限；导出包默认不带原始截图（架构文档 §6.2 第 11 项）。实现上：截图隐私遮罩在导出和缩略图统一应用、遮罩不可被预览缓存绕过（SEC-005）；日志/截图保留与清理策略，默认最小留存（SEC-006）；路径、用户名、窗口标题等脱敏（SEC-007）；轨迹导出、脱敏与导入校验（TRC-009）；保留策略与安全清理，不误删发布基线（TRC-010）。 |
| 缓解落点 | `packages/trace_format`（TRC-009/010）、控制面与 UI（SEC-005/006/007）；用例 SEC-006（被遮区域在缩略图、原图和诊断包中均不可见）、TRC-007、REL-004、UAT-009。 |

### TM-07 误用为在线游戏无人值守挂机（受保护目标硬锁）

| 项 | 内容 |
|---|---|
| 场景描述 | 用户把受保护在线游戏配置为运行目标，并试图通过修改项目文件启用 `real_input`、定时自动启动、自动重连，把工作台变成无人值守 Bot；或使用第三方分享的在线游戏刷怪项目包。 |
| 影响 | 违反产品边界与目标平台服务条款，账号风险由用户承担且产品不可承诺；项目被用于明确的非目标场景（一票否决项："受保护在线目标能够通过修改项目文件启用 RealInput"）。 |
| 缓解措施 | `protected_online` 硬锁：被标记为 protected_online 的目标默认只能观察、标注、回放和 Shadow（POL-003）；Shadow 模板硬编码 `real_input=false`、`unattended_schedule=false`、`auto_reconnect=false`（ADP-002）；静态检查拒绝在线目标无人值守配置（DOM-007）；策略拒绝定时自动启动与掉线弹窗自动继续（SAFE-021/022）；UI 不提供绕过按钮，硬锁不可由 UI 解锁（UI-016）；目标适配准入评审（ADP-003）。 |
| 缓解落点 | `packages/policy_engine`（POL-003、POL-002 模式机）、`examples/protected_online_demo`（反例）、UI（UI-003/UI-016）；用例 SAFE-020/021/022、AC-P0-06、UAT-011。 |

### TM-08 时钟/焦点状态不确定导致的输入错乱

| 项 | 内容 |
|---|---|
| 场景描述 | 系统时钟跳变或回拨导致超时/TTL 判定错乱；帧时间戳乱序导致决策基于过期帧；失焦、锁屏、用户切换、RDP 连接/断开瞬间前台状态不可知；采集黑帧或设备丢失时仍用旧帧决策。 |
| 影响 | 意图过期误判、输入时序错乱、在"不知道前台是什么"的窗口期发出输入；轨迹顺序失真使审计与回放不可信。 |
| 缓解措施 | 帧环形缓冲与单调时钟：时间戳单调、过期帧可识别（CAP-004）；跨模块时间同步与序列号，可处理系统时钟跳变（TRC-004）；可注入时钟与定时器，所有定时行为可回放（FSM-005）；任何不确定前台状态（锁屏、用户切换、RDP 变化）立即停止、不自动抢回焦点（INP-008）；采集连续黑帧/设备丢失时不使用旧帧继续决策，先停止输入再尝试回退，回退成功也需重新确认目标/标定（CAP-007、AC-P0-13）；目标最小化按策略停止，不用旧帧继续输入（CAP-011）。 |
| 缓解落点 | `packages/capture_api` 及采集适配器（CAP-004/007）、`services/input_broker`（INP-008）、`packages/trace_format`（TRC-004）、状态机（FSM-005）；用例 SAFE-016、CAP-010/011、AC-P0-13。 |

### TM-09 资产与运行记录被篡改（不可抵赖性破坏）

| 项 | 内容 |
|---|---|
| 场景描述 | 发布后模板、阈值或状态机被原地修改；或运行轨迹/日志被事后篡改，导致"当时到底运行了什么"无法回答，审计与回放基线失效。 |
| 影响 | 基于被篡改资产的运行可能绕过已评审的视觉/策略基线；轨迹失去不可抵赖性，事故定责与回归分析失效（一票否决项："轨迹不能指出实际使用的脚本、资产、策略和运行时版本"）。 |
| 缓解措施 | 资产来源、哈希和篡改检测：运行前与发布包比对，篡改即拒绝（SEC-004、VIS-013）；内容哈希与不可变发布目录：发布后内容不可原地修改，任何变化产生新版本（VER-002）；Manifest 冻结 Schema、运行时范围、资产、模型、策略和测试摘要（VER-001）；RunTrace 按会话形成哈希链，方便判断日志是否被修改（架构文档 §6.2 第 10 项）；导入损坏轨迹安全失败，不污染现有项目（TRC-008）。 |
| 缓解落点 | `packages/domain_model`（DOM-008 内容哈希）、`packages/trace_format`（TRC-001/002/008）、版本与发布（VER-001/002）；用例 VER-002、VIS-013、TRC-002。 |

### TM-10 资源耗尽（超大包 / 高压缩比 / 超长路径）

| 项 | 内容 |
|---|---|
| 场景描述 | 导入高压缩比、超大文件、重复文件或损坏 Zip 的项目包；配置含未知字段、深层嵌套、循环引用、NaN/Infinity、超长正则的脚本；磁盘写满时轨迹写入失败。 |
| 影响 | 内存/磁盘耗尽导致应用崩溃或系统卡死；解压炸弹在导入时占满磁盘；损坏输入若未安全失败可能污染现有项目。 |
| 缓解措施 | 达到限制后安全终止，不耗尽磁盘/内存（SEC-005 用例口径）；解包限制路径、类型和大小（CTL-004、SEC-002）；DSL/Schema 属性测试与模糊测试：随机输入不会导致崩溃、越权或无限循环（TST-003）；轨迹追加写、批量刷新与崩溃容错：损坏尾部可检测和截断（TRC-002）；磁盘接近满时停止保存非关键帧并安全停止，不破坏项目（PERF-007）。 |
| 缓解落点 | `services/control_plane`（CTL-004、SEC-002）、`packages/domain_model`（DOM-003、TST-003）、`packages/trace_format`（TRC-002）；恶意与异常输入集见任务文档 §8.3，测试集 TST-010。 |

## 3. 与质量闸门的对应

| 一票否决项（任务文档 §7.1） | 对应威胁 |
|---|---|
| 错误窗口、Shadow/Dry Run、失焦、锁屏、会话切换或过期意图仍产生真实输入 | TM-01、TM-05、TM-08 |
| 急停或异常退出后存在未释放按键 | TM-05 |
| 任意脚本/导入包可执行 Python、Shell、DLL、系统命令或绕过 Input Broker | TM-02、TM-03 |
| 受保护在线目标能够通过修改项目文件启用 RealInput | TM-07 |
| 项目迁移或回滚可导致资产、状态机和策略版本不一致 | TM-09 |
| 轨迹不能指出实际使用的脚本、资产、策略和运行时版本 | TM-09 |
| 导入包存在路径穿越、Zip Slip 或覆盖项目根目录之外文件的能力 | TM-03、TM-10 |

## 4. 维护约定

- 本清单随 M0 评审冻结；新增威胁（新目标类型、新插件机制、新 IPC 通道）必须先补充条目并评审，再进入实现；
- 每个里程碑候选版评审时核对第 3 节对应关系与相关用例结果；
- 修订走 GOV-003 责任人（TL/安全），并同步 `docs/safety/safety-boundaries.md` 与 PR 评审模板。
