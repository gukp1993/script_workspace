## 检查清单

### A. 架构不变量（`docs/safety/safety-boundaries.md` §2）

- [ ] 不涉及不变量 1-8 任一条；若涉及：
- [ ] 未新增绕过 `InputIntent` / Policy Guard / Input Broker 的输入路径（不变量 1/2）；
- [ ] 未削弱每批执行前的 HWND/PID/实例/前台/会话/TTL 复核（不变量 3）；
- [ ] 失焦、急停、父进程退出、锁屏、会话切换或状态不确定时仍先停止并释放全部按键（不变量 4）；
- [ ] 未引入任意 Python/Shell/DLL/系统命令执行入口（不变量 5）；
- [ ] 运行轨迹仍可追溯，未破坏确定性（同版本+同轨迹+同种子→同决策）（不变量 6）；
- [ ] 未为受保护在线目标开启真实输入或无人值守能力（不变量 7）。

### B. 禁止能力（`docs/safety/safety-boundaries.md` §3）

- [ ] 未实现进程隐藏、驱动隐藏、反作弊探测、内存读写、进程注入、封包截获/修改、硬件伪装、拟人化逃避检测、多账号集群或后台多开；
- [ ] 未引入 `exec`/`eval`/shell/DLL 加载入口或类似能力的间接途径；
- [ ] 能力默认拒绝未被改为默认允许；新增能力已声明并走授权模型（DOM-005）。

### C. 测试

- [ ] 新增/修改逻辑有单元或组件测试；错误、取消与安全停止路径有测试；
- [ ] P0 安全分支（若涉及）有 100% 用例覆盖；
- [ ] 契约测试/Schema 正反样例已更新（涉及消息、Schema 时）；
- [ ] `pytest tests -q` 与相关 CI 检查通过。

### D. 回放差异

- [ ] 本变更不影响感知/状态机/输入；若影响：
- [ ] 已附固定感知回放与原始帧回放差异报告，标注首个分歧点与受影响对象；
- [ ] 黄金数据集/基线已按规则更新，冻结验收集未被调参污染；
- [ ] 受影响的测试与项目包已按影响分析列出（任务文档 §16.2）。

### E. 文档

- [ ] 接口/Schema/使用文档已同步；示例仅使用 ArenaLab；
- [ ] 架构决策变化已新增/修订 ADR；
- [ ] `docs/safety/`、`docs/governance/` 基线文档若有出入已回改或提出修订。

### F. 日志与隐私

- [ ] 关键事件（拒绝、急停、失焦、预算耗尽、按键释放结果）有结构化日志与 `correlation_id`；
- [ ] 日志、截图、诊断输出未新增敏感信息泄露面（用户名、绝对路径、窗口标题敏感段、未遮罩原图）；
- [ ] 新增文件写入有路径边界与大小限制（不越出项目根目录）。
